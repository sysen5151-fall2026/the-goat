# NYC catalog

`nyc-poi-v1.json` is the published catalog for the current Wayly NYC MVP.

Each record has 1–4 interest tags from `PLACE_CATEGORIES` in `lib/nyc-types.ts` (the first is its primary type), a stable identifier, source URL, reviewed-on date, coordinates, USD planning allowance, access and price notes, and image and credit URLs. A planning allowance is not a live ticket price or a quote.
